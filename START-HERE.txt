CATCHY AI PRODUCT - START HERE

1. Extract the whole ZIP.
2. Install Python 3.11 or newer.
3. Windows: double-click START-WINDOWS.bat in the extracted folder.
   macOS/Linux: run sh start.sh in that folder.
4. The first run installs the Python dependencies, then opens the website.
5. KEEP THE TERMINAL WINDOW OPEN. Closing it stops the local server.

The default local setup needs no model key, PostgreSQL or Redis installation.
Docker Compose supplies PostgreSQL and Redis for a production-like setup.

To install on a phone, use a deployed HTTPS instance and the browser's
Add to Home screen feature. Your phone's localhost is NOT your computer.
For the Android native project and APK build, see docs/ANDROID.md.

English, Hindi and Telugu are beta. Other language coverage is labeled
inside the app. Scores are not fraud probabilities. No raw audio is stored.
Read README.md and docs/VERIFICATION.md before demonstrating the product.
